4. Detecta objetos con la cámara

La cámara debe estar conectada a la Raspberry Pi. Carga un detector de objetos, inicia la captura y observa los rectángulos. Mostrará las clases aprendidas en tu proyecto.

Carga un paquete de detección para utilizar esta función.

Una puntuación alta no garantiza un acierto. El detector puede omitir objetos o confundir sus clases; prueba distintas distancias, iluminación y fondos.

Piensa como investigador. Cambia el fondo, la iluminación o el objeto. ¿Mantiene su respuesta? La inferencia se ejecuta en la Raspberry Pi; el navegador muestra el resultado.
